# Сласти

Статический демонстрационный сайт кондитерской. Публичная версия — обычные HTML, CSS и JavaScript без сборки и без сервера.

Кейс для заказчика лежит отдельно: [portfolio-case/](portfolio-case/index.html).

## Запуск

Из корня проекта:

```bash
python -m http.server 5500
```

Открыть `http://127.0.0.1:5500/html/`. Файл `html/index.html` ссылается на `../css` и `../img`, поэтому сервер нужно запускать из корня, а не из папки `html`.

## Что публикуется

- `html/index.html` — сайт
- `css/`, `java/main.js`, используемые файлы в `img/`
- `portfolio-case/` — страница кейса

Папка `site/` — отдельная локальная копия на Next.js. Она не является опубликованной версией и в репозиторий не входит.
